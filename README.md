# Lucknow Metro Route Planner

A web-based transportation system designed to help users find metro routes, explore tourist places, and find nearby metro stations in Lucknow.

## Features

* Metro Route Planner
* BFS-based shortest route
* Dijkstra-based economical route
* Tourist Place Finder
* Nearest Metro Station
* Last-Mile Connectivity
* Smart Card Recharge
* Interactive Metro Map

## Technologies

* C++
* HTML5
* CSS3
* JavaScript
* LocalStorage

## Algorithms

* **BFS:** Used to find the route with the minimum number of stops.
* **Dijkstra's Algorithm:** Used to find the minimum-weight/economical route.

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run "index.html" using Live Server.
4. Open the generated localhost URL in your browser.
